Privacy policy

Last updated: 24 November 2026

This policy covers this website and the "Inside Everything uploader" tool (the "tool"), which uploads the Inside Everything channel's own videos to YouTube.

Who uses the tool

Only the owner of the Inside Everything YouTube channel. The tool is not available to the public and does not collect data from viewers or visitors.

YouTube API Services

The tool uses YouTube API Services. Use of YouTube through the tool is subject to the YouTube Terms of Service and the Google Privacy Policy.

What the tool accesses

With the owner's permission (Google sign-in), the tool can upload videos to the owner's channel and read basic channel information (the channel's name and ID) to confirm it is connected to the right channel. It does not access any other Google account data.

What is stored

The tool stores an authorization token for the owner's channel as an encrypted secret, and a log of which videos it uploaded (video ID, title, time). It stores no personal information about any other person.

Sharing

No data obtained through YouTube API Services is sold, shared with third parties or used for advertising.

Cookies and this website

This website sets no cookies and runs no analytics or tracking.

Revoking access and deleting data

The owner can revoke the tool's access at any time on the Google security settings page, security.google.com/settings/security/permissions. Stored authorization data is deleted when access is revoked; upload logs can be deleted on request.

Contact

Questions: contact the channel through its YouTube page, @InsideEverything-3D-Shorts.
